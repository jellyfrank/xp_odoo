# Odoo Implementation Manual

> 中文版本: [Odoo实施使用参考手册](../README.md)

This English edition is a practical implementation guide for companies and consultants who want to understand Odoo from real business scenarios, not only from isolated menu operations.

The Chinese edition remains the main source of the manual. The English edition will be expanded chapter by chapter, keeping the same implementation-oriented style: explain the business background first, then walk through the Odoo configuration, daily operation flow, screenshots, and practical notes.

The first translated chapter is the YunExpress integration guide, because logistics integration is a common requirement for cross-border sellers and it is a good example of how Odoo can be extended while still keeping the native delivery flow as the foundation.

Start here: [YunExpress Integration](chapter10/YUN.md)
